# BloodLink – Every Drop Connects a Life

BloodLink is a premier healthcare technology platform dedicated to bridging voluntary blood donors, authorized blood banks, and urgent patient requests across communities in real time.

## Overview

- **Real-Time Donor Discovery**: Filter voluntary donors by blood group, state, city, neighbourhood, and availability status.
- **Urgent Blood Requests Board**: Monitor emergency hospital requirements categorized by urgency tier (Urgent, Priority, Planned).
- **Authorized Blood Bank Directory**: Access verified blood donation centers, component laboratories (whole blood, platelets, plasma), and drive schedules.
- **Streamlined Voluntary Donor Registration**: Secure, validated registration workflow with strict validation for blood groups, contact methods, and location hierarchy.
- **Clinical Awareness & Education**: Comprehensive guides on eligibility, myth-busting, and donation preparation adhering to World Health Organization (WHO) best practices.

## Technology Stack

- **Framework**: [TanStack Start](https://tanstack.com/start) with TanStack Router (file-based routing)
- **UI & Styling**: [Tailwind CSS](https://tailwindcss.com) v4, Lucide React icons, Radix UI primitives
- **Typography**: Plus Jakarta Sans (Headings) & Inter (Body) self-hosted via Fontsource
- **Animation**: [Framer Motion](https://www.framer.com/motion/) with user-reduced-motion awareness
- **State & Data**: React Hook Form with Zod validation schemas
- **Testing**: Vitest with React Testing Library

## Getting Started

### Prerequisites

- Node.js (v20+ recommended)
- npm or bun

### Local Development

```sh
# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build & Test

```sh
# Run unit and integration tests
npm run test

# Build production assets
npm run build

# Preview production build locally
npm run preview
```
